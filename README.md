# Portfolio

Personal portfolio of Aman: LLM evaluation, backend systems and the things I've built.

Live: https://aman-cve.github.io/portfolio/

A static site with no build step. Open `index.html`, or serve the folder with any static server.

| File | What it does |
| --- | --- |
| `index.html` | All page content |
| `styles.css` | Layout, theme and CSS 3D motion |
| `script.js` | Page interactions: loader, reveals, ring gallery, cursor |
| `scene.js` | The WebGL scene (three.js from a CDN): core, 3D lettering, embers |
| `thumbs.js` | Live wireframe artwork on the project cards |

To use real screenshots on the project cards, replace each `<canvas class="project__art">` in `index.html` with an `<img>`.
